# Test UI

A simple React web application built with TypeScript and Material-UI components.

## Features

- Horizontally and vertically centered layout
- Three interactive buttons with different styles and icons
- File dropzone that supports both drag-and-drop and click-to-select
- File list display showing selected files with their sizes
- Snackbar notifications for user feedback

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Navigate to the test-ui directory:
   ```bash
   cd apps/test-ui
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Usage
- Click any of the three buttons to see a notification
- Drag and drop files onto the dropzone, or click to open a file picker
- Selected files are displayed with their names and sizes

## Technologies Used
- React 18 (TypeScript)
- Material-UI (MUI) v5
- Emotion (for styling)
